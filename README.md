# 张语桐 - 个人简历网站

一个基于 HTML + Tailwind CSS 构建的个人简历展示网站，用于展示个人背景、实习经历、项目成果和联系方式。

## 在线访问

[https://my-resume-sigma-beryl.vercel.app/](https://my-resume-sigma-beryl.vercel.app/)

## 技术栈

- **HTML5** — 页面结构
- **Tailwind CSS**（CDN）— 样式框架
- **Google Fonts (Inter)** — 字体
- **原生 JavaScript** — 交互功能（导航栏滚动监听、移动端菜单、轮播图等）

## 页面结构

| 区块 | 说明 |
|------|------|
| 首页 (Hero) | 个人简介、标签云、照片展示 |
| 教育背景 | 山东大学 & 香港中文大学教育经历 |
| 实习经历 | 好奇小森林、中国邮政、高顿三段实习详情 |
| 竞赛、创业和其他项目 | 项目案例展示 |
| 联系我 | 联系方式、社交媒体链接 |

## 本地运行

直接用浏览器打开 `index.html` 即可：

```bash
open index.html
```

无需安装任何依赖，所有样式和脚本均通过 CDN 引入。

## 部署

本项目已部署至 **Vercel**，连接 Git 仓库后自动部署，每次推送 `main` 分支会自动更新线上站点。

## 自定义

- **颜色主题**：深绿色 `#1a3a2a` / 米白色 `#faf6f0`
- **图片资源**：替换 `zyt.PNG` 及轮播图目录下的图片文件即可更新视觉内容
- **PDF 简历**：替换根目录下的 PDF 文件并更新导航栏中的下载链接

## 功能特性

- 响应式布局（适配移动端/平板/桌面）
- 固定导航栏 + 滚动高亮
- 图片轮播组件
- 平滑滚动
- PDF 简历下载
